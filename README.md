# 🎮 鈴鹿高専祭 カジュアルゲーム集

鈴鹿工業高等専門学校の高専祭（学校祭）向けに制作したブラウザゲーム集です。
来場者がスマートフォン・PCどちらからでも遊べる軽量なゲームを提供します。

## ゲーム一覧

| ゲーム | 説明 | URL |
|--------|------|-----|
| [高専ダッシュ！](./kosendash) | 5学科エリアを走り抜けるエンドレスランナー | https://kosendash.vercel.app |

## リポジトリ構成

```
SNCT-Casual-games/
└── kosendash/          # 高専ダッシュ！（エンドレスランナー）
    ├── app/            # Next.js App Router ページ・APIルート
    ├── components/     # Reactコンポーネント
    └── lib/            # ゲームエンジン・Supabaseクライアント
```

## 新しいゲームを追加するには

1. ルート直下に新しいディレクトリを作る（例: `quiz/`）
2. `create-next-app` や任意のフレームワークで初期化
3. Vercelに別プロジェクトとしてデプロイ
4. このREADMEのゲーム一覧に追記

## 技術スタック（共通）

- **フレームワーク**: Next.js (App Router)
- **デプロイ**: Vercel
- **データベース**: Supabase（スコア・リーダーボード）
- **言語**: TypeScript
