# ゲーム仕様

## ゲーム概要

鈴鹿高専の5学科をテーマにしたタイムアタック型ステージクリアゲーム。
プレイヤーは学科を1つ選び、その学科のステージを走り切るまでの **クリアタイム** を競う。

### 操作方法

| 操作 | PC | スマートフォン |
|------|-----|--------------|
| ジャンプ | スペース / ↑ キー | タップ |
| 二段ジャンプ | スペース / ↑ （空中で） | 空中でタップ |
| 浮上（化学） | スペース / ↑ 長押し | タップ長押し |
| 一時停止 | P / Esc キー | ⏸ボタン |

- **段差はジャンプで乗り越える**（機械工学科のみ。壁として機能し、ジャンプしないとスクロールが止まる）
- ジャンプは「障害物を飛び越える」「段差を乗り越える」ほか、学科ごとのギミック（電池を取る・バグを踏む・炉をくぐる）に使う

## 学科とステージ

### 5学科ステージ

学科選択画面で1つを選ぶ。選んだ学科のステージのみをプレイする。

| 学科 | 障害物 | 地形の特徴 |
|------|--------|-----------|
| 機械工学科 | レンチ（低・細）・スプリング（中・上下）・ロボットアーム（中高・伸縮）・フライホイール（大・回転）・ハンマー（高い壁）・コンベア（低・幅広）／6種をサイズ帯と動きで個性化（複合パターンあり） | 落とし穴なし・段差を積み上げた「山登り」階段（登り切った頂上から急落下） |
| 電気電子工学科 | 抵抗器（低・幅広）・コイル（低・細）・回路基板（中）・トランジスタ（中）・コンデンサ（やや高）・電子（中・上下浮遊）・放電リング（大・回転）・テスラコイル（高）・鉄塔（二段ジャンプ必須）／8種をサイズ帯と動きで個性化 | **平坦・穴なし**（充電サバイバル型／後述） |
| 電子情報工学科 | 踏める敵＝緑の🐛バグ1種（頭上に▼の踏める合図）＋踏めない赤系障害8種（構文エラー・malloc/free点滅ゲート・ヌルポインタ・マージコンフリクト・セグフォ・スタックオーバーフロー・ファイアウォール・ブロックチェーンの塔）。バグと障害物は独立したタイマーで並行して出現 | **平坦・穴なし**（デバッグ踏みつけ型／後述） |
| 生物応用化学科 | 上下から伸びるパイプ（試薬管・細胞壁）が迫る。化学・生物ゾーンの切替で見た目が変化 | **地面なし**（液体スイム型／後述） |
| 材料工学科 | 赤熱した金属の塊（hot_ingot）が地面を流れてくる。タイミングよくハンマーで叩く | **平坦・穴なし**（鍛えてカン！／後述） |

### 開始前ブリーフィング画面

学科を選んでゲームに入ると、スタート前にその学科専用の説明画面を表示する（`components/Game.tsx` の
未スタート状態 ＋ `lib/game/stage-info.ts`）。学科テーマカラーを使ったポップなカードUIで、以下を見せる：

- 学科の絵文字・名前・キャッチコピー
- 「この学科は？」：学科の簡単な紹介
- 「ステージの特徴」：そのステージ固有のギミック（2〜3項目）
- 「操作方法」：ジャンプ（材料工学科はハンマー）とノックバック（ゲームオーバー無し）の案内

「▶ スタート！」ボタンで実際のプレイが始まる。文言は `STAGE_INFO`（departmentId 1〜5）で管理する。

### ゴール

各ステージの終端にはフラッグポール（マリオ風）が存在する。
ポールに近づくにつれてグローが強まり、750px以内で「GOAL」テキストがフェードイン。
頂点には学科 emoji が入った旗が波打ちアニメーションで表示される。

### ステージの流れ

- ステージ距離：`STAGE_LENGTH = 70000`（ミスなしで約1分半〜2分半。自動プレイでは機械・電気電子 約105秒、電子情報 約89秒、材料 約79秒、生物応化 約149秒）
- ゲームは1/60秒刻みで進む（固定タイムステップ）。画面のリフレッシュレート（60/90/120Hz）や端末の重さで速さが変わらない
- 進むほど速度・障害物密度が上昇（序盤は遅く簡単、終盤は速く密度が高い）
- ゴールポールに到達するとクリア・クリアタイムが記録される

```
速度: lerp(SPEED_START=8, SPEED_END=15, 進捗/STAGE_LENGTH)
障害物スポーン間隔: SPAWN_GAPS[departmentId]（材料工学科は時間基準の予定キュー）を参照
```

## 地形システム

地形は学科ごとに異なる（`lib/game/terrain.ts` の `buildStage()`）。段差があるのは機械工学科だけで、生物応化は地面なし、それ以外は平坦。

### 段差

- 地面の高さが変わるポイント（1段 = `STEP_H = 40px`）
- **ジャンプしないと壁として機能**し、スクロールが止まる（`isBlockedByStep()` により制御）
- ジャンプして段差の上面より高い位置を通過すると乗り越えられる
- 段差・階段の途中には障害物をスポーンしない（`isFlatAt()` で平坦区間を判定）

### 山登り階段（機械工学科）

- 機械工学科ステージは**落とし穴を使わず**、段差を複数段（2〜4段）積み上げた「山型階段」が地形ギミック
- 1段40pxを上って頂上の平坦部に達する。**下りは無く**、頂上の端から基準高さへ一気に急落下する
- 各段はジャンプで越える。頂上からの落下は壁判定が発火せず自然落下で降りる

### 充電サバイバル（電気電子工学科）

機械工学科が「地形の高さを読む空間ゲーム」なのに対し、電気電子工学科は「充電を維持する**時間軸の資源管理ゲーム**」として差別化している。すべて `departmentId === 2` のみで稼働する。

- 地形は**完全な平坦・穴なし**（`buildStageFlat()`）。プレイヤーは「障害物回避」＋「充電維持」の二重課題に集中する
- 画面上部に**充電ゲージ**（⚡）を表示。残量で色が緑→黄→赤に変化し、低残量で点滅警告
- ゲージは**常に減少**（`CHARGE_DRAIN = 0.16/frame`）。**0になると MISS**（既存のMISS/復活システムを流用し、復活後は `CHARGE_REVIVE = 50` から再開）
- 走路に🔋**電池アイテム**がスポーン（`BATTERY_GAP`）。**必ずジャンプしないと届かない高さ**（地面から74〜120px）に配置され、拾うと `BATTERY_REFILL = 35` 回復。走っているだけでは取れず、充電のために能動的なジャンプを強制する
- **被弾はチャージ大幅減（`CHARGE_HIT_COST = 30`）＋ノックバック**の二重ペナルティ
- 関連定数は `constants.ts`、ゲージ描画は `hud-renderer.ts`、電池描画は `item-renderer.ts`

### デバッグ踏みつけ（電子情報工学科）

機械＝空間・電気電子＝資源に対し、電子情報工学科は「**避ける**から**踏んで倒す（デバッグ）**へ」の能動アクション軸で差別化する。すべて `departmentId === 3` のみで稼働し、操作は**ジャンプ（＋二段ジャンプ）**を維持する。

- 地形は**完全な平坦・穴なし**（`buildStageFlat()`）。踏む／越える／タイミングで通り抜けるに集中させる
- **踏めるのは緑の🐛バグ1種のみ**（`stompable: true`）。頭上に点滅する▼で「踏める」を明示。地上・空中で上下・大物・2〜3連チェインのバリエーションで出る
- **踏めない障害はすべて赤系**で統一し、緑バグと一目で区別できるようにする：
  - `syntax_error`（閉じ忘れ `}` ＋赤い波線）／`null_pointer`（null＋虚空への矢印）／`merge_conflict`（HEAD/=======/>>>>>>>）／`segfault`（SIGSEGV＋16進ダンプ）
  - `stack_overflow`（`call()` が積み上がる高壁・フルジャンプで越える）
  - **二段ジャンプ必須の高壁**：`firewall`（炎のレンガ壁）／`blockchain`（ブロックの塔）。高さ144〜156pxで、シングルジャンプではギリギリ届かず**ダブルジャンプ**でのみ安定して越えられる
- **踏みつけ判定**：落下中（`pvy > 0`）に踏める敵の上面（`py - pvy <= o.y + STOMP_MARGIN`）へ着地で成立 → バウンド（`STOMP_BOUNCE`）。側面や下から触れた場合はミスにならず、バグが消滅してコンボは継続される
- **コンボ → デバッグモード**：バグを踏むたび `combo` が**累積**（時間ではリセットしない）。`COMBO_NEEDED`（=3）匹で **デバッグモード**（`DEBUG_FRAMES`）に突入。背景がコード雨化＋**スクロール加速**（`DEBUG_SPEED_MULT`＝タイム短縮）＋その間は無敵で踏める敵を自動処理
- **malloc/free 点滅ゲート**（`malloc_free`）：周期的に malloc（実体＝当たり判定あり）と free（消滅＝すり抜け）を繰り返す**タイミング突破型**。判定 `mallocSolid(phase, frame)`（`MALLOC_PERIOD` / `MALLOC_SOLID`）を engine の衝突判定と drawer の見た目で共有。消えた瞬間に走り抜けるか、実体時はジャンプで越える
- HUD にコンボゲージ（💻）と「DEBUG MODE」バナー＋残り時間バーを表示
- 関連定数は `constants.ts`、踏み/モード/点滅判定のロジックは `engine.ts`、各障害の描画は `obstacle-drawers.ts`、背景演出は `background-renderers.ts` の `bgCode()`

### 液体スイム（生物応用化学科）

機械＝空間・電気電子＝資源・電子情報＝能動に対し、生物応用化学科は「**重力と浮力のコントロール**」という物理挙動の全く異なる操作感で差別化する。すべて `departmentId === 4` のみで稼働する。

- **操作の変更**：スペースキー・↑キー・画面タップを**長押し**している間、浮力（上方向の推力）が発生して上昇する。離すと重力で沈降する（Flappy Birdや水中のような操作感）。
- **地形と壁**：地面の概念がない。かわりに画面の上下端が水槽の壁として機能し、ぶつかるとノックバックする（穴落下や場外への飛び出しは無い）。
- **障害物**：上下から伸びるパイプ状の障害物（`試薬管`、`細胞壁`コロニー）が出現し、間をすり抜ける。
- **ゾーン切替**：ステージ進行度に応じて「化学ゾーン（青系）」と「生物ゾーン（緑黄系）」が交互に切り替わる。背景の色調や障害物の見た目が一定時間ごとに変化する。
- 関連定数は `constants.ts`（`SWIM_THRUST`, `SWIM_DRAG`等）、スイム専用の物理挙動は `engine.ts` の `updateBio()`、ゾーン切替は `areas.ts` の `bioZone()` で管理。

### 鍛えてカン！（材料工学科）
 
機械＝空間・電気電子＝資源・電子情報＝能動・生物応化＝浮力操作に対し、材料工学科は「**流れてくる金属をタイミングよく叩く**」という軸で差別化する。教員の研究キーワード「加工熱処理」「結晶粒微細化」を題材にしている。すべて `departmentId === 5` のみで稼働する。

- **操作**：このステージのみ、タップ（スペース・↑キー・クリック）はジャンプではなく「**ハンマーで叩く**」操作になる（ジャンプはしない）。自キャラは常に地上を走る
- **地形**：**平坦・穴なし**（`buildStageFlat()`）
- **判定とルール**：
  - 自キャラの前方175pxにある輪（`FORGE_RING_OFFSET`）に塊の中心が重なるタイミングで叩く（残りフレーム `t` で判定）
  - **PERFECT**（−2.5 ≤ `t` ≤ +2.5）：ヒットストップ2フレーム、火花、画面揺れ、「カン！」を大きく表示。塊は薄い板になって後ろへ飛ぶ。速度段階が +1（最大4段階、最大1.4倍）
  - **GOOD**（+2.5 < `t` ≤ +4.5 または −6.5 ≤ `t` < −2.5）：「コン」を表示。塊は板になる。速度段階が −1（0未満にはしない）
  - **はやい**（+4.5 < `t` ≤ +20）：「はやい！」を表示。速度段階が0に戻り、12フレーム硬直
  - **空振り**（塊が +20 より遠い、または塊がない）：罰なし。12フレーム硬直
  - **被弾**（叩けなかった塊が自キャラに当たる）：ノックバック、速度段階と連続回数を0にリセット、「おそい！」を表示
- **視覚的予告**：
  - **予告の輪**：塊の中心の周囲に輪を描き、塊が輪に近づくほど縮む（osu! の収縮円と同様、距離基準で縮むため速度変化でもずれない）
  - **炉の脈動**：背景の炉の火が、次の塊が届くタイミングに合わせて明るくなり、到達時に最大になる
  - **速度段階の見た目**：0＝赤、1〜2＝オレンジ、3＝黄色、4＝白熱。最高速（段階4）では流線と残像が付く
- **序盤チュートリアル**：
  - 開始から1.5秒は塊を出さず、「🔨 タップでたたけ！」を画面中央に表示
  - 最初の2個の塊は、輪に近づくと世界が20%の速度（スロー）になり、輪が点滅して待機。タップすれば PERFECT 扱い
- **パターンの展開**：
  - 単発、2連（タタン：間隔18フレーム）、3連（タタタン：間隔18フレーム）、休み
  - ステージ進捗に応じて4区間（0〜25%, 25〜50%, 50〜75%, 75〜100%）に分かれ、後ろの区間ほどパターンが詰まる。区間切り替え時に約1秒の休みとカットインを表示
- **結果画面**：クリア後に粗い粒の塊と細かい粒の板の演出を表示（`components/MatProductReveal.tsx`）
- 関連定数は `constants.ts`（`FORGE_*`）、ロジックは `engine.ts` の `strike()` / `updateForgeHold()`、スポーンは `spawner.ts` の `updateForge()`、描画は `mat-renderers.ts`

### 落とし穴

- 地面がなくなるポイント（幅110px以上）／現在は**どの学科のステージでも使用していない**（engine の落下フローとして仕組みだけ残している）
- **ジャンプで越えないと落ちる**
- 落下演出あり（地面から30px落ちてスクロール停止→画面外まで落ちてからMISS）
- 落ちると後退ペナルティ（MISSシステムへ）

## ペナルティシステム（MISSシステム）

このゲームに「ゲームオーバー」はない。障害物や穴はすべて **後退ペナルティ** になる。

### ミス〜復活フロー

**障害物ヒット時：**
```
衝突
  ↓ [ヒットストップ: 6f = 0.1秒]  衝撃感演出
  ↓ [MISS オーバーレイ: 90f = 1.5秒]  物理停止・赤背景表示
      "MISS!" + "← XXXpt 後退" → "GET READY..." へクロスフェード
  ↓ [復活スロー: 75f = 1.25秒]  速度を SPEED_START に固定
      "GET READY..." フェードアウト表示
  ↓ 通常プレイ再開（速度がステージ進度に応じて自動上昇）
```

**穴落下時（演出あり）：**
```
穴ゾーン（targetGroundY=Infinity）に入り、地面から30px落下
  ↓ isFallingIntoHole フラグ ON → スクロール停止（世界が静止）
  ↓ プレイヤーだけ重力で落ち続ける
  ↓ 画面外（CANVAS_H + 60 = 340px）に達したら knockback 発火
  ↓ 以降は障害物ヒット時と同じ MISS フローへ
```

### 後退量

| ペナルティ | 後退量 |
|-----------|--------|
| 障害物ヒット | 120pt（`KNOCKBACK_AMOUNT`） |
| 穴落下 | 200pt（`HOLE_KNOCKBACK`） |

### 無敵時間

ノックバック後は90フレーム（約1.5秒）の無敵時間が付与される。

## リーダーボード

- **学科別・全期間**のクリアタイム上位10件を表示（タイムが**短いほど上位**）
- 同じニックネームで何度クリアしても、ランキングには**最速タイムの1件だけ**が載る（順位もニックネーム単位で数える）
- クリア直後のリザルト画面に順位（「今回のタイムなら何位か」。自己ベスト更新ならランキングの順位と同じ）と「M人中」、自己ベスト（更新したら「🎉 自己ベスト更新！」）を表示。シェアページの順位も同じ数え方
- クリアタイムはサーバー（DB関数）で検証してから登録する（学科ごとの最短タイム・プレイ開始からの経過時間・1プレイ1回・NGワード。詳細は [doc/database.md](database.md)）
- 運営は不適切な記録を `hidden` で隠せる（[doc/operations.md](operations.md)）
- ランキング表示は CDN に5秒キャッシュするので、登録から反映まで最大10秒ほどかかることがある

## リザルト・シェア

- 「もう一度！」で同じ学科をすぐ始める（ブリーフィングは出さない）。「学科を選ぶ」「ランキング」「タイトルに戻る」も選べる
- 材料工学科はクリア後に粗い粒の塊と細かい粒の板の演出（`components/MatProductReveal.tsx`）
- 登録できたら X / LINE / 端末の共有メニューでシェアできる。共有URL `/r/{記録ID}` はタイム・学科・順位入りの画像（OGP）付き

## 一時停止

- ⏸ボタン・P / Esc キーで一時停止。メニューから「再開」「最初からやり直す」「学科選択に戻る」
- 別のアプリやタブに切り替えたとき、スマホを縦向きにしたときは自動で一時停止する
- 一時停止中はタイムが進まない（クリアタイムはゲーム内時間）

## GameEngine インターフェース（`lib/game/engine.ts`）

```typescript
const engine = new GameEngine(
  canvasElement,                   // null ならロジックだけ動かす（テスト・ボット用）
  departmentId,                    // 1〜5 の学科ID
  (result: GameClearResult) => {}, // クリア時コールバック
  { seed?: number, silent?: boolean },  // 乱数シード（再現用）・効果音/パーティクルなし
)

engine.start()        // ゲームループ開始（固定タイムステップ：1/60秒刻みで update、描画は rAF ごと）
engine.jump()         // ジャンプ入力
engine.setThrust(on)  // 浮上の長押し（生物応用化学科）
engine.pause() / engine.resume() / engine.togglePause() / engine.paused
engine.destroy()      // ゲームループ停止（アンマウント時）

// テスト・ボット用
engine.step()         // 1ステップ進める（描画なし）
engine.clone()        // 状態を丸ごと複製（乱数・スポーナー含む）
engine.snapshot       // 進捗・タイム・ミス数・障害物などの読み取り
```
