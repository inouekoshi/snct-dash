# ゲーム仕様

## ゲーム概要

鈴鹿高専の5学科をテーマにしたタイムアタック型ステージクリアゲーム。
プレイヤーは学科を1つ選び、その学科のステージを走り切るまでの **クリアタイム** を競う。

### 操作方法

| 操作 | PC | スマートフォン |
|------|-----|--------------|
| ジャンプ | スペース / ↑ キー | タップ |
| 二段ジャンプ | スペース / ↑ （空中で） | 空中でタップ |
| 一時停止 | P / Esc キー | ⏸ボタン |

- **段差は自動乗り越え**（ジャンプ不要）
- ジャンプは「穴を越える」「障害物を飛び越える」ために使う

---

## 学科とステージ

### 5学科ステージ

学科選択画面で1つを選ぶ。選んだ学科のステージのみをプレイする。

| 学科 | ステージの特徴・ギミック |
|------|------------------------|
| 機械工学科 | 詳細は今後設計 |
| 電気電子工学科 | 詳細は今後設計 |
| 電子情報工学科 | 詳細は今後設計 |
| 生物応用化学科 | 詳細は今後設計 |
| 材料工学科 | 詳細は今後設計 |

各学科のクリア条件・ギミック詳細は今後学科ごとに個別に設計する。

### ステージの流れ

- 1ステージの目安プレイ時間：**約2分**（距離 `STAGE_LENGTH = 6000` 単位）
- 進むほど速度・障害物密度が上昇（序盤は遅く簡単、終盤は速く密度が高い）
- ゴールに到達するとクリア

```
速度: lerp(SPEED_START=4, SPEED_END=15, 進捗/STAGE_LENGTH)
障害物: 進捗に応じてスポーン間隔が短縮
```

## 地形システム

今のゲームと異なり、地面は一本の平面ではない。**段差**と**落とし穴**が存在する。

### 段差

- 地面の高さが変わるポイント
- プレイヤーは自動で乗り越える（ジャンプ不要）
- 走り続けていれば自動で対応

### 落とし穴

- 地面がなくなるポイント
- **ジャンプで越えないと落ちる**
- 落ちると **少し後ろに戻される**（ジュゲム演出）

---

## ペナルティシステム

このゲームに「ゲームオーバー」はない。障害物や穴はすべて **後退ペナルティ** になる。

### 障害物ヒット

- 障害物に当たると **スクロールが巻き戻される**（世界が前に流れ、プレイヤーが後退した見た目）
- 一定フレームの **無敵時間** が付与される
- タイムが実質増加する

### 落とし穴

- 穴に落ちると **即座に後退**（ジュゲム演出で引き上げられる）
- 穴の手前に戻される

---

## アイテムシステム

コース上にアイテムが出現する。取得すると一時的な効果が発動する。

| アイテム | 効果 | 備考 |
|---------|------|------|
| 時間停止 | 一定フレームスクロールが止まる・タイマーも止まる | タイムを実質短縮できる |
| 無敵 | 一定フレーム障害物に当たらない | ペナルティを回避できる |

各学科のステージに固有のアイテムを追加する可能性あり（今後設計）。

---

## フェアネス機構

| 機構 | 内容 |
|------|------|
| コヨーテタイム | 地面から離れた直後5フレーム以内のジャンプを有効扱い |
| 先行入力バッファ | 着地直前8フレームのジャンプ入力を着地時に自動実行 |
| ノックバック後無敵 | 障害物ヒット後、一定フレーム無敵 |

---

## リーダーボード

- **学科別・全期間**のクリアタイム上位10件を表示
- タイムが**短いほど上位**
- 同一プレイヤーが複数回プレイした場合、**最速タイムのみ** ランキングに残る（未実装・要設計）

## GameEngine インターフェース（`lib/game/engine.ts`）

```typescript
const engine = new GameEngine(
  canvasElement,
  departmentId,           // 1〜5 の学科ID
  (timeMs: number) => {   // クリア時コールバック
    console.log(timeMs)
  }
)

engine.start()        // ゲームループ開始
engine.jump()         // ジャンプ入力
engine.togglePause()  // 一時停止/再開
engine.pause()        // 一時停止
engine.resume()       // 再開
engine.destroy()      // ゲームループ停止（アンマウント時）
```

### GameClearResult 型（`lib/types.ts`）

```typescript
export interface GameClearResult {
  timeMs: number       // クリアタイム（ミリ秒）
  departmentId: number // 学科ID（1〜5）
}
```
