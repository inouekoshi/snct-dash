# ゲーム仕様

## ゲーム概要

### 操作方法

| 操作 | PC | スマートフォン |
|------|-----|--------------|
| ジャンプ | スペース / ↑ キー | タップ |
| 二段ジャンプ | スペース / ↑ （空中で） | 空中でタップ |
| 一時停止 | P / Esc キー | ⏸ボタン |

### 5学科エリア

エリアは40秒ごとに切り替わり、ループします。エリアが進むほど速度・障害物密度が上昇します。下表の速度は1周目の基本値です（周回が増えると倍率がかかります）。

| エリア | 学科 | 速度（基本） | 障害物の特徴 | 背景 |
|--------|------|------------|------------|------|
| 1 | 機械工学科 | 5 | 歯車・ボルト・ピストン（入門） | 大型歯車シルエット |
| 2 | 電気電子工学科 | 7.5 | 回路・コイル・コンデンサ＋天井障害物 | 回路基板グリッド |
| 3 | 電子情報工学科 | 10.5 | バグ・モニター・チップ（上下ホップ）＋天井障害物 | マトリックス数字 |
| 4 | 生物応用化学科 | 13.5 | 細菌・フラスコ・キノコ（密集）＋天井障害物 | 浮遊気泡 |
| 5 | 材料工学科 | 17 | クリスタル・インゴット・格子（高密度）＋天井障害物 | 結晶格子 |

### スコアシステム

| 要素 | 点数 |
|------|------|
| 走行距離 | 速度÷8 点/フレーム（切り上げ）× 倍率 |
| コイン取得 | +10点 × 倍率 |
| エリアノーミスクリア | +100点 × 倍率（ボーナス後に倍率が上昇） |
| シールド所持中にシールドアイテム取得 | +50点 |

#### スコア倍率システム

ノーミスでエリアを完走するたびに倍率が上昇します。

| 状態 | 倍率 |
|------|------|
| 初期 / ダメージ後 | ×1 |
| 1エリアノーミスクリア | ×2 |
| 2エリア連続ノーミス | ×3（上限） |

- ダメージ（シールド消費）で即座に×1にリセット
- エリア遷移時のアニメーションに「×2 BONUS!」などと表示
- HUDのSCORE表示に現在の倍率が付く（例：`SCORE 12,345 ×2`）

### シールドシステム

- スタート時にシールドを1つ所持
- 障害物に当たるとシールドを消費し、**2秒間無敵**になる
- シールドなしで当たるとゲームオーバー
- コース上に出現する🛡アイテムを取るとシールドが回復する
- すでにシールドがある状態で拾うと +50点ボーナス

### リーダーボード

- **全期間 TOP20**：通算ハイスコア
- **当日 TOP10**：高専祭当日限定ランキング（`FESTIVAL_DATE` 環境変数で制御）
- ニックネームを入力してプレイ開始、ゲームオーバー後に自動登録

## 難易度システム

### 周回スケーリング

エリア5を完走するとエリア1に戻り「周回数（lap）」がカウントされます。周回が増えるごとにゲーム全体の難易度が上昇します。

**速度スケーリング：**

```
effectiveSpeed = AREA_SPEEDS[area] × (1 + lap × 0.15)  ← 上限3.0倍
```

| 周回 | Area 1 速度 | Area 5 速度 |
|------|------------|------------|
| 1周目 | 5.0 | 17.0 |
| 2周目 | 5.75 | 19.6 |
| 3周目 | 6.5 | 22.1 |
| 5周目 | 8.0 | 27.2 |

**スポーン間隔スケーリング：**

```
spawnScale = max(0.5, 1 − lap × 0.07)
```

- 周回が増えるほど障害物の出現間隔が短縮（最短で基本値の50%）

HUDとエリア遷移テキストに「LAP N」が表示されます。リザルト画面でも最高周回数を確認できます。

### 天井障害物（Stalactite）

エリア2以降、天井から垂れ下がるトゲ型障害物が出現します。

- 地面を走行中は当たらないが、**ジャンプすると当たる**設計
- 地面障害物との組み合わせで「跳ぶべき/跳んではいけない」の判断が必要になる
- 30%の確率で2連続スポーン
- 天井障害物の真下に警告破線を表示

出現間隔はエリアと周回数に応じて短縮されます。

### 速度バーストフェーズ（RUSH）

約15秒ごとに2.5秒間、速度が**1.8倍**になるバーストフェーズが自動発動します。

- HUDに「⚡ RUSH! ⚡」と表示
- 画面に速度線エフェクトが走る
- **発動時に画面シェイク**で迫力を演出
- 周回スケーリングと重複するため、後半周回でのバーストは非常に高速になる

### フェアネスシステム

「理不尽な死」を減らすための2つの仕組みが実装されています。

#### コヨーテタイム
地面から足が離れた直後**5フレーム以内**にジャンプを押した場合、まだ地面にいたとみなして1回目のジャンプとして処理します。「ギリギリで踏み切れなかった」判定を防ぎます。

#### ジャンプ先行入力バッファ
2段ジャンプを使い切った状態でジャンプを押しても、**8フレーム以内に着地すれば**着地と同時に自動でジャンプします。「着地に合わせてジャンプを押したのに空振りした」を防ぎます。

#### ヒットストップ
シールドでダメージを吸収した瞬間に**約0.1秒（6フレーム）ゲームが止まります**。衝突の衝撃が伝わり、次の行動を考える猶予が生まれます。

## 内部実装の仕様

### GameEngine クラス（`lib/game/engine.ts`）

ゲームロジックの全てを担う中心クラスです。

```typescript
const engine = new GameEngine(canvasElement, (result: GameResult) => {
  // ゲームオーバー時に呼ばれるコールバック
  console.log(result.score, result.distance, result.maxArea, result.lap)
})

engine.start()       // ゲームループ開始
engine.jump()        // ジャンプ入力
engine.togglePause() // 一時停止/再開
engine.pause()       // 一時停止
engine.resume()      // 再開
engine.destroy()     // ゲームループ停止（コンポーネントのアンマウント時）
```

#### GameResult 型（`lib/types.ts`）

```typescript
export interface GameResult {
  score: number    // 最終スコア
  distance: number // 走行距離（整数）
  maxArea: number  // 到達した最大エリア番号（1〜5）
  lap: number      // 完走した周回数（0 = 1周目でゲームオーバー）
}
```

### エリアのチューニング（`lib/game/areas.ts` / `lib/game/constants.ts`）

各エリアのビジュアルテーマは `lib/game/areas.ts` の `AREAS` オブジェクトで定義されています。
色や名前を変えたい場合はここを編集します。

速度・スポーン間隔などのゲームバランスは `lib/game/constants.ts` の定数で調整できます。

```typescript
// エリアごとのスクロール速度（大きいほど速い）
export const AREA_SPEEDS: Record<number, number> = { 1: 5, 2: 7.5, 3: 10.5, 4: 13.5, 5: 17 }

// エリアごとの障害物スポーン間隔 [最小フレーム数, ランダム幅]
export const SPAWN_GAPS: [number, number][] = [
  [0, 0],
  [110, 60],
  [85, 50],
  [65, 40],
  [50, 32],
  [36, 26],
]

// 1エリアあたりの時間（フレーム数）
export const AREA_DURATION = 40 * 60

// 周回難易度スケーリング
export const LAP_SPEED_SCALE = 0.15   // lapごとに速度+15%
export const LAP_SPAWN_SCALE = 0.07   // lapごとにスポーン間隔-7%
export const MIN_SPAWN_SCALE = 0.5    // スポーン間隔の最小係数（50%）
export const MAX_SPEED_SCALE = 3.0    // 速度の最大倍率上限
```

### 効果音（`lib/game/sound.ts`）

音声ファイルを一切使わず、Web Audio API でプロシージャルに生成します。
ゲーム起動時のバンドルサイズに影響しません。

| 関数 | タイミング | 備考 |
|------|-----------|------|
| `playJump()` | ジャンプ時 | |
| `playCoin(combo)` | コイン取得時 | `combo` が増えるほど音程が上がる（最大+48%）。1.5秒取得なしでリセット |
| `playGameOver()` | ゲームオーバー時 | |
| `playAreaChange()` | エリア切替時 | |
| `playHurt()` | シールドでダメージ吸収時 | |
| `playShieldGet()` | シールドアイテム取得時 | |
