# ゲーム仕様

## ゲーム概要

鈴鹿高専の5学科をテーマにしたタイムアタック型ステージクリアゲーム。
プレイヤーは学科を1つ選び、その学科のステージを走り切るまでの **クリアタイム** を競う。

### 操作方法

| 操作 | PC | スマートフォン |
|------|-----|--------------|
| ジャンプ | スペース / ↑ キー | タップ |
| 二段ジャンプ | スペース / ↑ （空中で） | 空中でタップ |
| 一時停止 | P / Esc キー | ⏸ボタン |

- **段差はジャンプで乗り越える**（壁として機能し、ジャンプしないとスクロールが止まる）
- ジャンプは「穴を越える」「障害物を飛び越える」「段差を乗り越える」ために使う

## 学科とステージ

### 5学科ステージ

学科選択画面で1つを選ぶ。選んだ学科のステージのみをプレイする。

| 学科 | 障害物 | 地形の特徴 |
|------|--------|-----------|
| 機械工学科 | レンチ（低・細）・スプリング（中・上下）・ロボットアーム（中高・伸縮）・フライホイール（大・回転）・ハンマー（高い壁）・コンベア（低・幅広）／6種をサイズ帯と動きで個性化（複合パターンあり） | 落とし穴なし・段差を積み上げた「山登り」階段（登り切った頂上から急落下） |
| 電気電子工学科 | 抵抗器（低・幅広）・コイル（低・細）・回路基板（中）・トランジスタ（中）・コンデンサ（やや高）・電子（中・上下浮遊）・放電リング（大・回転）・テスラコイル（高）・鉄塔（二段ジャンプ必須）／8種をサイズ帯と動きで個性化 | **平坦・穴なし**（充電サバイバル型／後述） |
| 電子情報工学科 | 踏める敵＝緑の🐛バグ1種（頭上に▼の踏める合図）＋踏めない赤系障害8種（構文エラー・malloc/free点滅ゲート・ヌルポインタ・マージコンフリクト・セグフォ・スタックオーバーフロー・ファイアウォール・ブロックチェーンの塔）。バグと障害物は独立したタイマーで並行して出現 | **平坦・穴なし**（デバッグ踏みつけ型／後述） |
| 生物応用化学科 | （現在選択不可・ロック状態） | （未実装） |
| 材料工学科 | （現在選択不可・ロック状態） | （未実装） |

### 開始前ブリーフィング画面

学科を選んでゲームに入ると、スタート前にその学科専用の説明画面を表示する（`components/Game.tsx` の
未スタート状態 ＋ `lib/game/stage-info.ts`）。学科テーマカラーを使ったポップなカードUIで、以下を見せる：

- 学科の絵文字・名前・キャッチコピー
- 「この学科は？」：学科の簡単な紹介
- 「ステージの特徴」：そのステージ固有のギミック（2〜3項目）
- 「操作方法」：ジャンプ操作とノックバック（ゲームオーバー無し）の案内

「▶ スタート！」ボタンで実際のプレイが始まる。文言は `STAGE_INFO`（departmentId 1〜5）で管理する。

### ゴール

各ステージの終端にはフラッグポール（マリオ風）が存在する。
ポールに近づくにつれてグローが強まり、750px以内で「GOAL」テキストがフェードイン。
頂点には学科 emoji が入った旗が波打ちアニメーションで表示される。

### ステージの流れ

- ステージ距離：`STAGE_LENGTH = 70000`（約1分半でクリア）
- 進むほど速度・障害物密度が上昇（序盤は遅く簡単、終盤は速く密度が高い）
- ゴールポールに到達するとクリア・クリアタイムが記録される

```
速度: lerp(SPEED_START=8, SPEED_END=15, 進捗/STAGE_LENGTH)
障害物スポーン間隔: SPAWN_GAPS[departmentId] を参照
```

## 地形システム

地面は一本の平面ではない。**段差**と**落とし穴**が存在する。

### 段差

- 地面の高さが変わるポイント（1段 = `STEP_H = 40px`）
- **ジャンプしないと壁として機能**し、スクロールが止まる（`isBlockedByStep()` により制御）
- ジャンプして段差の上面より高い位置を通過すると乗り越えられる
- 段差・階段の途中には障害物をスポーンしない（`isFlatAt()` で平坦区間を判定）

### 山登り階段（機械工学科）

- 機械工学科ステージは**落とし穴を使わず**、段差を複数段（2〜4段）積み上げた「山型階段」が地形ギミック
- 1段40pxを上って頂上の平坦部に達する。**下りは無く**、頂上の端から基準高さへ一気に急落下する
- 各段はジャンプで越える。頂上からの落下は壁判定が発火せず自然落下で降りる

### 充電サバイバル（電気電子工学科）

機械工学科が「地形の高さを読む空間ゲーム」なのに対し、電気電子工学科は「充電を維持する**時間軸の資源管理ゲーム**」として差別化している。すべて `departmentId === 2` のみで稼働する。

- 地形は**完全な平坦・穴なし**（`buildStageElec()`）。プレイヤーは「障害物回避」＋「充電維持」の二重課題に集中する
- 画面上部に**充電ゲージ**（⚡）を表示。残量で色が緑→黄→赤に変化し、低残量で点滅警告
- ゲージは**常に減少**（`CHARGE_DRAIN = 0.16/frame`）。**0になると MISS**（既存のMISS/復活システムを流用し、復活後は `CHARGE_REVIVE = 50` から再開）
- 走路に🔋**電池アイテム**がスポーン（`BATTERY_GAP`）。**必ずジャンプしないと届かない高さ**（地面から74〜120px）に配置され、拾うと `BATTERY_REFILL = 35` 回復。走っているだけでは取れず、充電のために能動的なジャンプを強制する
- **被弾はチャージ大幅減（`CHARGE_HIT_COST = 30`）＋ノックバック**の二重ペナルティ
- 関連定数は `constants.ts`、ゲージ描画は `hud-renderer.ts`、電池描画は `item-renderer.ts`

### デバッグ踏みつけ（電子情報工学科）

機械＝空間・電気電子＝資源に対し、電子情報工学科は「**避ける**から**踏んで倒す（デバッグ）**へ」の能動アクション軸で差別化する。すべて `departmentId === 3` のみで稼働し、操作は**ジャンプ（＋二段ジャンプ）**を維持する。

- 地形は**完全な平坦・穴なし**（`buildStageCode()`）。踏む／越える／タイミングで通り抜けるに集中させる
- **踏めるのは緑の🐛バグ1種のみ**（`stompable: true`）。頭上に点滅する▼で「踏める」を明示。地上・空中で上下・大物・2〜3連チェインのバリエーションで出る
- **踏めない障害はすべて赤系**で統一し、緑バグと一目で区別できるようにする：
  - `syntax_error`（閉じ忘れ `}` ＋赤い波線）／`null_pointer`（null＋虚空への矢印）／`merge_conflict`（HEAD/=======/>>>>>>>）／`segfault`（SIGSEGV＋16進ダンプ）
  - `stack_overflow`（`call()` が積み上がる高壁・フルジャンプで越える）
  - **二段ジャンプ必須の高壁**：`firewall`（炎のレンガ壁）／`blockchain`（ブロックの塔）。高さ144〜156pxで、シングルジャンプではギリギリ届かず**ダブルジャンプ**でのみ安定して越えられる
- **踏みつけ判定**：落下中（`pvy > 0`）に踏める敵の上面（`py - pvy <= o.y + STOMP_MARGIN`）へ着地で成立 → バウンド（`STOMP_BOUNCE`）。側面や下から触れた場合はミスにならず、バグが消滅してコンボは継続される
- **コンボ → デバッグモード**：バグを踏むたび `combo` が**累積**（時間ではリセットしない）。`COMBO_NEEDED`（=3）匹で **デバッグモード**（`DEBUG_FRAMES`）に突入。背景がコード雨化＋**スクロール加速**（`DEBUG_SPEED_MULT`＝タイム短縮）＋その間は無敵で踏める敵を自動処理
- **malloc/free 点滅ゲート**（`malloc_free`）：周期的に malloc（実体＝当たり判定あり）と free（消滅＝すり抜け）を繰り返す**タイミング突破型**。判定 `mallocSolid(phase, frame)`（`MALLOC_PERIOD` / `MALLOC_SOLID`）を engine の衝突判定と drawer の見た目で共有。消えた瞬間に走り抜けるか、実体時はジャンプで越える
- HUD にコンボゲージ（💻）と「DEBUG MODE」バナー＋残り時間バーを表示
- 関連定数は `constants.ts`、踏み/モード/点滅判定のロジックは `engine.ts`、各障害の描画は `obstacle-drawers.ts`、背景演出は `background-renderers.ts` の `bgCode()`

### 落とし穴

- 地面がなくなるポイント（幅110px以上）／**機械・電気電子・電子情報以外**のステージで使用
- **ジャンプで越えないと落ちる**
- 落下演出あり（地面から30px落ちてスクロール停止→画面外まで落ちてからMISS）
- 落ちると後退ペナルティ（MISSシステムへ）

## ペナルティシステム（MISSシステム）

このゲームに「ゲームオーバー」はない。障害物や穴はすべて **後退ペナルティ** になる。

### ミス〜復活フロー

**障害物ヒット時：**
```
衝突
  ↓ [ヒットストップ: 6f = 0.1秒]  衝撃感演出
  ↓ [MISS オーバーレイ: 90f = 1.5秒]  物理停止・赤背景表示
      "MISS!" + "← XXXpt 後退" → "GET READY..." へクロスフェード
  ↓ [復活スロー: 75f = 1.25秒]  速度を SPEED_START に固定
      "GET READY..." フェードアウト表示
  ↓ 通常プレイ再開（速度がステージ進度に応じて自動上昇）
```

**穴落下時（演出あり）：**
```
穴ゾーン（targetGroundY=Infinity）に入り、地面から30px落下
  ↓ isFallingIntoHole フラグ ON → スクロール停止（世界が静止）
  ↓ プレイヤーだけ重力で落ち続ける
  ↓ 画面外（CANVAS_H + 60 = 340px）に達したら knockback 発火
  ↓ 以降は障害物ヒット時と同じ MISS フローへ
```

### 後退量

| ペナルティ | 後退量 |
|-----------|--------|
| 障害物ヒット | 120pt（`KNOCKBACK_AMOUNT`） |
| 穴落下 | 200pt（`HOLE_KNOCKBACK`） |

### 無敵時間

ノックバック後は90フレーム（約1.5秒）の無敵時間が付与される。

## アイテムシステム

コース上にアイテムが出現する。取得すると一時的な効果が発動する。

| アイテム | 効果 | 備考 |
|---------|------|------|
| 時間停止 | 一定フレームスクロールが止まる・タイマーも止まる | タイムを実質短縮できる |
| 無敵 | 一定フレーム障害物に当たらない | ペナルティを回避できる |

> 現在はアイテムのスポーン機能は未実装（型定義・状態変数のみ）。

## フェアネス機構

| 機構 | 内容 |
|------|------|
| コヨーテタイム | 地面から離れた直後5フレーム以内のジャンプを有効扱い |
| 先行入力バッファ | 着地直前8フレームのジャンプ入力を着地時に自動実行 |
| ノックバック後無敵 | ミス後、90フレーム（1.5秒）無敵 |
| 復活スロー | ミス後75フレーム（1.25秒）は最低速度で再開 |

## リーダーボード

- **学科別・全期間**のクリアタイム上位10件を表示
- タイムが**短いほど上位**
- 同一プレイヤーが複数回プレイした場合、**最速タイムのみ** ランキングに残る（未実装・要設計）

## GameEngine インターフェース（`lib/game/engine.ts`）

```typescript
const engine = new GameEngine(
  canvasElement,
  departmentId,                    // 1〜5 の学科ID
  (result: GameClearResult) => {   // クリア時コールバック（GameClearResult型）
    // result.timeMs, result.departmentId
  }
)

engine.start()        // ゲームループ開始
engine.jump()         // ジャンプ入力
engine.togglePause()  // 一時停止/再開
engine.pause()        // 一時停止
engine.resume()       // 再開
engine.destroy()      // ゲームループ停止（アンマウント時）
```

### GameClearResult 型（`lib/types.ts`）

```typescript
export interface GameClearResult {
  timeMs: number       // クリアタイム（ミリ秒）
  departmentId: number // 学科ID（1〜5）
}
```
