# ゲーム仕様

## ゲーム概要

鈴鹿高専の5学科をテーマにしたタイムアタック型ステージクリアゲーム。
プレイヤーは学科を1つ選び、その学科のステージを走り切るまでの **クリアタイム** を競う。

### 操作方法

| 操作 | PC | スマートフォン |
|------|-----|--------------|
| ジャンプ | スペース / ↑ キー | タップ |
| 二段ジャンプ | スペース / ↑ （空中で） | 空中でタップ |
| 一時停止 | P / Esc キー | ⏸ボタン |

- **段差はジャンプで乗り越える**（壁として機能し、ジャンプしないとスクロールが止まる）
- ジャンプは「穴を越える」「障害物を飛び越える」「段差を乗り越える」ために使う

---

## 学科とステージ

### 5学科ステージ

学科選択画面で1つを選ぶ。選んだ学科のステージのみをプレイする。

| 学科 | 障害物 | 地形の特徴 |
|------|--------|-----------|
| 機械工学科 | レンチ（低・細）・スプリング（中・上下）・ロボットアーム（中高・伸縮）・フライホイール（大・回転）・ハンマー（高い壁）・コンベア（低・幅広）／6種をサイズ帯と動きで個性化（複合パターンあり） | 落とし穴なし・段差を積み上げた「山登り」階段（登り切った頂上から急落下） |
| 電気電子工学科 | 回路基板・コイル・コンデンサ | **平坦・穴なし**（充電サバイバル型／後述） |
| 電子情報工学科 | バグ（上下移動）・モニター・チップ | 標準的な穴配置 |
| 生物応用化学科 | バクテリア群・フラスコ・キノコ | 標準的な穴配置 |
| 材料工学科 | クリスタル（段差配置）・インゴット・ラティス | 標準的な穴配置 |

### ゴール

各ステージの終端にはフラッグポール（マリオ風）が存在する。
ポールに近づくにつれてグローが強まり、750px以内で「GOAL」テキストがフェードイン。
頂点には学科 emoji が入った旗が波打ちアニメーションで表示される。

### ステージの流れ

- ステージ距離：`STAGE_LENGTH = 70000`（テスト時は `15000`）
- 進むほど速度・障害物密度が上昇（序盤は遅く簡単、終盤は速く密度が高い）
- ゴールポールに到達するとクリア・クリアタイムが記録される

```
速度: lerp(SPEED_START=4, SPEED_END=15, 進捗/STAGE_LENGTH)
障害物スポーン間隔: SPAWN_GAPS[departmentId] を参照
```

## 地形システム

地面は一本の平面ではない。**段差**と**落とし穴**が存在する。

### 段差

- 地面の高さが変わるポイント（1段 = `STEP_H = 40px`）
- **ジャンプしないと壁として機能**し、スクロールが止まる（`isBlockedByStep()` により制御）
- ジャンプして段差の上面より高い位置を通過すると乗り越えられる
- 段差・階段の途中には障害物をスポーンしない（`isFlatAt()` で平坦区間を判定）

### 山登り階段（機械工学科）

- 機械工学科ステージは**落とし穴を使わず**、段差を複数段（2〜4段）積み上げた「山型階段」が地形ギミック
- 1段40pxを上って頂上の平坦部に達する。**下りは無く**、頂上の端から基準高さへ一気に急落下する
- 各段はジャンプで越える。頂上からの落下は壁判定が発火せず自然落下で降りる

### 充電サバイバル（電気電子工学科）

機械工学科が「地形の高さを読む空間ゲーム」なのに対し、電気電子工学科は「充電を維持する**時間軸の資源管理ゲーム**」として差別化している。すべて `departmentId === 2` のみで稼働する。

- 地形は**完全な平坦・穴なし**（`buildStageElec()`）。プレイヤーは「障害物回避」＋「充電維持」の二重課題に集中する
- 画面上部に**充電ゲージ**（⚡）を表示。残量で色が緑→黄→赤に変化し、低残量で点滅警告
- ゲージは**常に減少**（`CHARGE_DRAIN = 0.18/frame`）。**0になると MISS**（既存のMISS/復活システムを流用し、復活後は `CHARGE_REVIVE = 50` から再開）
- 走路に🔋**電池アイテム**がスポーン（`BATTERY_GAP`）。地上〜やや高め（ジャンプ取得）に配置され、拾うと `BATTERY_REFILL = 35` 回復
- **被弾はチャージ大幅減（`CHARGE_HIT_COST = 30`）＋ノックバック**の二重ペナルティ
- 関連定数は `constants.ts`、ゲージ描画は `hud-renderer.ts`、電池描画は `item-renderer.ts`

### 落とし穴

- 地面がなくなるポイント（幅110px以上）／**機械工学科・電気電子工学科以外**のステージで使用
- **ジャンプで越えないと落ちる**
- 落下演出あり（地面から30px落ちてスクロール停止→画面外まで落ちてからMISS）
- 落ちると後退ペナルティ（MISSシステムへ）

## ペナルティシステム（MISSシステム）

このゲームに「ゲームオーバー」はない。障害物や穴はすべて **後退ペナルティ** になる。

### ミス〜復活フロー

**障害物ヒット時：**
```
衝突
  ↓ [ヒットストップ: 6f = 0.1秒]  衝撃感演出
  ↓ [MISS オーバーレイ: 90f = 1.5秒]  物理停止・赤背景表示
      "MISS!" + "← XXXpt 後退" → "GET READY..." へクロスフェード
  ↓ [復活スロー: 75f = 1.25秒]  速度を SPEED_START に固定
      "GET READY..." フェードアウト表示
  ↓ 通常プレイ再開（速度がステージ進度に応じて自動上昇）
```

**穴落下時（演出あり）：**
```
穴ゾーン（targetGroundY=Infinity）に入り、地面から30px落下
  ↓ isFallingIntoHole フラグ ON → スクロール停止（世界が静止）
  ↓ プレイヤーだけ重力で落ち続ける
  ↓ 画面外（CANVAS_H + 60 = 340px）に達したら knockback 発火
  ↓ 以降は障害物ヒット時と同じ MISS フローへ
```

### 後退量

| ペナルティ | 後退量 |
|-----------|--------|
| 障害物ヒット | 120pt（`KNOCKBACK_AMOUNT`） |
| 穴落下 | 200pt（`HOLE_KNOCKBACK`） |

### 無敵時間

ノックバック後は90フレーム（約1.5秒）の無敵時間が付与される。

## アイテムシステム

コース上にアイテムが出現する。取得すると一時的な効果が発動する。

| アイテム | 効果 | 備考 |
|---------|------|------|
| 時間停止 | 一定フレームスクロールが止まる・タイマーも止まる | タイムを実質短縮できる |
| 無敵 | 一定フレーム障害物に当たらない | ペナルティを回避できる |

> 現在はアイテムのスポーン機能は未実装（型定義・状態変数のみ）。

---

## フェアネス機構

| 機構 | 内容 |
|------|------|
| コヨーテタイム | 地面から離れた直後5フレーム以内のジャンプを有効扱い |
| 先行入力バッファ | 着地直前8フレームのジャンプ入力を着地時に自動実行 |
| ノックバック後無敵 | ミス後、90フレーム（1.5秒）無敵 |
| 復活スロー | ミス後75フレーム（1.25秒）は最低速度で再開 |

## リーダーボード

- **学科別・全期間**のクリアタイム上位10件を表示
- タイムが**短いほど上位**
- 同一プレイヤーが複数回プレイした場合、**最速タイムのみ** ランキングに残る（未実装・要設計）

## GameEngine インターフェース（`lib/game/engine.ts`）

```typescript
const engine = new GameEngine(
  canvasElement,
  departmentId,                    // 1〜5 の学科ID
  (result: GameClearResult) => {   // クリア時コールバック（GameClearResult型）
    // result.timeMs, result.departmentId
  }
)

engine.start()        // ゲームループ開始
engine.jump()         // ジャンプ入力
engine.togglePause()  // 一時停止/再開
engine.pause()        // 一時停止
engine.resume()       // 再開
engine.destroy()      // ゲームループ停止（アンマウント時）
```

### GameClearResult 型（`lib/types.ts`）

```typescript
export interface GameClearResult {
  timeMs: number       // クリアタイム（ミリ秒）
  departmentId: number // 学科ID（1〜5）
}
```
