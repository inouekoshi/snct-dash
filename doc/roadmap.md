# 高専ダッシュ！ ロードマップ

## ビジョン

> **「鈴鹿高専祭の来場者が、15分の空き時間に何度も挑戦したくなる、5学科の魅力が詰まったタイムアタックゲーム」**

3つの柱：
1. **触りやすさ**：1タップで遊べる、説明不要のシンプル操作
2. **奥深さ**：学科固有のギミックを熟知して最速タイムを目指す戦略性
3. **高専らしさ**：5学科のアイデンティティがギミックレベルで感じられるテーマ性

---

## ゲーム仕様（確定）

### 基本仕様

- **タイムアタック制**：ステージをクリアするまでの時間を競う
- **学科選択**：スタート時に1学科を選択し、その学科のステージのみをプレイ
- **ステージは5つ**（= 5学科）。1ステージ約2分
- **ゲームオーバーなし**：障害物に当たるとノックバック（後退）、穴に落ちると少し戻される
- **リトライ自由**：いつでも最初からやり直し可
- **操作はジャンプのみ**（段差は自動乗り越え）
- **ランキング**：学科別・全期間・クリアタイム昇順

### 廃止した旧仕様

以下は旧エンドレスランナー時代の仕様で、現在は廃止：

| 廃止要素 | 廃止理由 |
|---------|---------|
| エンドレスランナー（周回制） | タイムアタック制に移行 |
| 5学科の自動エリア切替 | 学科選択＋固定ステージに移行 |
| シールド・ゲームオーバー制 | ノックバック制に移行 |
| コイン・スコア倍率 | タイムアタック制に不要 |
| 当日ランキング（FESTIVAL_DATE） | 全期間ランキングに一本化 |
| scoresテーブル | stage_clearsテーブルに置き換え |

## リスクと制約

| リスク | 内容 | 対策 |
|--------|------|------|
| **Supabase Free 同時接続60** | 祭当日に詰む可能性 | REST（PostgREST）経由なので直接接続を使わない。ランキングは CDN に5秒キャッシュ |
| **Vercel Hobby の商用利用問題** | Hobby は個人・非商用のみ | 課金・広告・報酬なしの学生作品なら範囲内と考えられる。判断材料は [operations.md](operations.md#vercel-hobby-プランで公開してよいか)（[#5](https://github.com/inouekoshi/snct-dash/issues/5)） |
| **スパム・不正タイム** | クリアタイムの改ざん | 対策済み：DB関数で検証（最短タイム・経過時間・1プレイ1登録・NGワード）、直接 INSERT 禁止。残るのは「本当に待って理論値近くのタイムを送る」ことだけ（運営が `hidden` で隠せる） |
| **Supabase Free の自動停止** | 約7日アクセスがないと停止し、API が 500 になる | Vercel Cron で毎日ウォームアップ（実装済み）。停止時はダッシュボードで Restore |
| **当日ピーク負荷** | 同時数百人のDB書き込み集中 | DB関数の計測で十分な余裕を確認（[operations.md](operations.md#負荷の見積もり)） |

## 設計原則

1. **5秒で楽しめるか**：チュートリアル無しで遊べることを最優先
2. **学科の特色がギミックレベルで出ているか**：単なる色・名前変更ではなく、ステージの仕掛けで差別化
3. **コア操作（ジャンプ）を壊さないか**：操作を増やすより、既存操作の意味付けを深める
4. **フェアネスを保つ**：「理不尽に死んだ」と感じさせない。ノックバック後の無敵・コヨーテタイムを維持
5. **ジューシーであれ**：ノックバック演出・効果音・パーティクルを惜しまない
6. **モバイル横向きで快適か**：実機（スマホ）での動作を常に基準にする
