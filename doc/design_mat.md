# 材料工学科ステージ（学科ID=5）「製品ができるまでラン」設計書

## なぜこのステージにしたか

材料工学科は、5学科のうち最後まで未実装で、学科選択画面でロックされていた。設計にあたっての要望は2つあった。

- デザインは**分子模型（ボール&スティック）**を参考にする
- 既存4ステージ（機械＝空間／電気電子＝資源／電子情報＝能動／生物応化＝浮力操作）と**コンセプトを被らせない**

### 鈴鹿高専 材料工学科のリサーチ（2026-10）

| 項目 | 内容 |
|------|------|
| 学科のメッセージ | 「あなたはもう材料の世界にいる」「こんな材料を一緒に作ってみませんか?!」。原子から始めて、金属・ガラス・プラスチックの性質、評価・加工までを学ぶ |
| 学科サイトの世界観 | 「材料の宇宙」：電子顕微鏡で見た金属表面を星に、結晶方位マップをオーロラに見立てた絵 |
| 位置づけ | 前身は金属工学科（1966年）。機械・材料系で材料を専門に学べる高専は全国に3校だけ |
| 教員の研究 | 熱処理・金属組織（2名）、水素透過合金・合金設計、無機材料・分光、環境材料、バイオマテリアル、電気化学、有機合成 |
| 卒業生の成果 | ゴムのように曲がるチタン製眼鏡フレーム、カーボン製ゴルフクラブ、スマホカメラレンズの微細加工機 |

ここから、学科の魅力の核を**「原子の並びを変えたり加工したりすると性質が変わり、身近な製品になる」**と整理した。

出典：[材料工学科（公式）](https://www.suzuka-ct.ac.jp/department/department_index/mse/)、[材料工学科サイト](http://www.suzuka-ct.ac.jp/mse/)、[受験相談FAQ](https://www.suzuka-ct.ac.jp/mse/school.pdf)

### 検討した案と落とした理由

批評エージェント3体（ゲームデザイン／来場者UX／実装）と計5ラウンド議論して絞り込んだ。

| 案 | 内容 | 落とした理由 |
|----|------|-------------|
| 分子組み立て | 目標分子の原子を選んで拾う | スマホでは原子の色を判別できない。化学寄りで生物応化と被る。電池回収とも手触りが同じ |
| 多層格子レール／周期境界 | 上下2層のレールをジャンプで行き来する／画面の上下がつながる | 「高さを読む」機械と被る。「穴＝罰」のルールが逆転して理不尽に感じる |
| 結合スイング | 原子にぶら下がって振り子で穴を渡る | 面白いが、「結合」は化学寄りで学科とのつながりが弱い |
| 磁性反転 | タップで重力が反転し、床と天井を行き来する | 学科に磁性の研究がない |
| 水素透過 | 水素原子になって金属膜をすり抜ける | 来場者に伝わりにくい。生物応化のパイプくぐりと構造が同じ |
| 合金設計 | 元素を拾って組成を変える | HUD を読む負荷が高い。電池回収と被る |
| 熱処理ラン（単独） | ゲートで軟／硬を選ぶ | 良案。最終的に本案の「熱処理区間」として取り込んだ |
| 超弾性ラン（単独） | 板バネに「ぶつかるのが正解」 | 単独では2分もたない。熱処理区間の「しなる」として取り込んだ |

## コンセプト

**自分自身が材料になり、加工されるたびに性質（物理）が変わる。** ゴールでチタン眼鏡フレームが完成する。

ブリーフィングのキャッチコピーは「とかす→のばす→きたえる！」。

## ステージ構成

区間は `matPhase(stageProgress)` で毎回計算する（`STAGE_LENGTH` に対する比率で持つ）。状態を保存しないので、ノックバックで前の工程に戻っても矛盾しない。

| 工程 | 区間 | 自キャラ | 性質 | 課題 |
|------|------|---------|------|------|
| 溶解 | 0〜28% | 液滴（光る球） | 着地のたびに小さく自動で弾む。当たり判定の高さ34 | 低めの結晶・インゴットを跳ぶ |
| 圧延 | 28〜56% | 薄板（銀の板） | 当たり判定の高さ22 | ローラーは跳ばずに潜る、インゴットは跳ぶ |
| 熱処理 | 56〜95.5% | 金属片 | ゲートで「しなる」「かたい」に変わる | 看板 → ゲート → 課題のセット |
| 検査 | 95.5%〜 | 金属片 | — | 障害なし。顕微鏡の視野の演出 |

- 各工程の入口には工程ゲート（ボール&スティックのアーチ）があり、初めて通ったときに0.8秒のカットインを出す
- 区間境界の前後400px（`MAT_SAFE_MARGIN`）には障害物を出さない。当たり判定の高さが急に変わって即被弾するのを防ぐため

### 熱処理区間

ルールは「看板と同じ色のゲートを通れ」の1つだけにしている。看板・ゲート・課題は `spawnHeatSet()` で、決まった位置関係でまとめて生成する。

| ゲート | 通り方 | 状態 | 課題 |
|--------|--------|------|------|
| 🔥炉（空中） | ジャンプでくぐる | **しなる**（焼なまし） | 金色の板バネに当たってよい。曲がって0.3秒減速した後、形が戻る反動で約1秒加速する。上から勢いよく当たるほど加速が大きい（上限1.4倍） |
| 💧水槽（地上） | 走って通る | **かたい**（焼入れ） | もろい結晶壁（高さ146、二段ジャンプが必要）を体当たりで砕く |

- 状態が合っていない場合
  - 板バネに当たると通常のノックバック
  - 結晶壁は二段ジャンプで越えられるが、越えると1秒減速する
- 最初の1セットだけは炉を地上に置き、必ず「しなる」を体験させる（チュートリアル）
- 状態は `matStateUntilX`（stageX 基準）までで、セットを抜けると通常（灰色）に戻る。速度が変わってもゲートと状態の範囲がずれないように、フレーム数ではなく位置で管理している
- 炉をジャンプでくぐったときの着地で板バネを飛び越えないよう、板バネはゲートから遠めに置く（`HEAT_CHALLENGE_OFFSET.flex = 820`）

## ビジュアル

- **背景「材料の宇宙」**：工程が進むほど倍率が上がる
  - 星（顕微鏡で見た金属表面）→ オーロラ（結晶方位）→ 原子格子 → 顕微鏡の視野
- **地面**：ボール&スティックの原子列。並び方が工程で変わる
  - 溶解＝ばらばら → 圧延＝横に引き伸ばし → 熱処理＝互い違いに整列
- **自キャラ**：液滴 → 薄板 → 金属片
  - 金属片の内部組織も状態で変わる（しなる＝丸い結晶粒、かたい＝針状組織）
  - 頭上に「🔥しなる」「💧かたい」を表示する
- **結果画面**：工程が並んでチタン眼鏡フレームが組み上がり、「卒業生が実現させた製品」と紹介する（`components/MatProductReveal.tsx`）

## 実装の場所

| 内容 | ファイル |
|------|---------|
| 区間判定・定数（`matPhase` / `MAT_*` / `HEAT_*`） | `lib/game/constants.ts` |
| 状態・タイマー・セット生成（`updateMat()` / `bendSpring()` / `applyItem()`） | `lib/game/engine.ts` |
| 溶解・圧延の障害物と熱処理セットの生成（`spawnMat()` / `spawnHeatSet()`） | `lib/game/spawner.ts` |
| 背景・地面・自キャラ・ゲート・看板・障害物・HUD・カットインの描画 | `lib/game/mat-renderers.ts` |
| 結果画面の製品完成演出 | `components/MatProductReveal.tsx` |
| ブリーフィング文言 | `lib/game/stage-info.ts` |

材料工学科固有の処理はすべて `isMat`（`departmentId === 5`）で分岐しており、他学科の物理には手を入れていない。

## 調整のポイント

| 定数 | 意味 |
|------|------|
| `MELT_BOUNCE_VY` | 溶解の自動バウンドの強さ |
| `MAT_HITBOX_H` | 工程ごとの当たり判定の高さ |
| `ROLL_GAP` | ローラーと床のすき間（薄板22pxなら潜れる） |
| `MAT_SPAWN_GAPS` | 溶解・圧延の出現間隔。圧延はローラーの手前で必ず着地できるよう広め |
| `HEAT_SET_GAP` | 熱処理セット同士の間隔 |
| `MAT_BOOST_MAX` / `MAT_BOOST_FRAMES` | 板バネの加速の強さ・長さ |
| `MAT_SLOW_FRAMES` / `MAT_SLOW_MULT` | 結晶壁を迂回したときの減速 |

実機での調整は [Issue #2](https://github.com/inouekoshi/snct-dash/issues/2) で管理する。
